STILL DREAMING V4.1 | 체험용 더미 홈페이지
제작일: 2026-10-12

[상태]
이 패키지는 V4.1 화면과 상호작용을 확인하기 위한 더미/시안입니다.
GitHub Pages에 자동 배포하지 않았으며, 사용자 승인 전까지 기존 공개 홈페이지는 변경되지 않습니다.
압축 해제 후 index.html을 브라우저에서 열어 미리 볼 수 있습니다.

[주요 변경]
1. 승인된 얼굴 이미지를 픽셀 변경 없이 유지하고, 커서 움직임에 따른 인물 위치/기울기/조명 변화를 강화했습니다.
   PC 마우스에 반응합니다. 모바일 터치 환경과 움직임 줄이기 설정에서는 움직임을 최소화합니다.
2. 메인 버튼: '나의 이야기 탐색하기' → '배지열 Profile 보기'
3. 카테고리: Experience / Story / Dreams (화면에 보이는 My 제거)
4. 세 카드의 색상·아이콘·태그·클릭 안내를 달리하고, 마우스 오버 및 선택 반응을 강화했습니다.
5. 기존 9개 학력·경력·사회공헌 이력, 기존 6컷 커리어 웹툰, 한영 전환을 유지했습니다.
6. Dreams에 리더십, 네트워킹, 창업 준비, 피자 브랜드·기부를 담은 미래 웹툰을 추가했습니다.
7. 모바일/태블릿의 히어로 레이아웃과 카드 배치를 조정했습니다.

[압축 파일 구성 / 모두 같은 폴더에 유지]
index.html            홈페이지 본문
style.css             모든 화면의 스타일 및 애니메이션
app.js                메뉴/카드/모달/언어 전환/마우스 반응
portrait.webp         이전 V4.0에서 사용한 승인 인물 이미지 (픽셀 동일)
webtoon-preview.webp  기존 커리어 웹툰 썸네일
career-webtoon.webp   기존 커리어 웹툰 전체
future-webtoon.png    새롭게 추가된 미래 웹툰 (창작 시안)
README_설치_및_폼연결.txt  이 안내문

[구현 확인]
- PC / 태블릿 / 모바일: 콘텐츠 레이아웃 및 가로 넘침
- 카드 3개 클릭 및 패널 전환, 이력 펼치기, 양쪽 웹툰 모달, 언어 전환
- 브라우저 JavaScript 오류 유무

[Google Forms 관련 중요한 안내]
- 이전에 제공한 응답자용 Google Forms 링크가 연결되어 있습니다.
- '교류 신청하기'를 클릭하면 실제 Google Form이 새 창으로 열립니다.
  더미 사이트라도 실제 양식을 통해 제출하면 실제 응답으로 저장될 수 있으므로 주의하세요.
- 이 정적 사이트 자체에는 방문자의 이름·이메일·소속이 저장되지 않습니다.
- Google Sheets의 관리자 URL/스프레드시트 ID는 사이트 HTML·JS에 넣지 않았습니다.
- 양식의 개인정보 필수동의, 소속 필수 입력, 공개 접근, 응답 스프레드시트 연결 여부는
  현재 확인할 수 없어 정식 운영 전에 관리자가 직접 테스트해야 합니다.
- Google Sheets는 '제한됨' 설정을 유지하고 공개 링크로 바꾸지 마세요.

[나중에 배포하기로 결정했다면]
1. 기존 GitHub Pages 저장소의 파일을 백업합니다.
2. ZIP 압축을 풀고 위 HTML/CSS/JS/이미지 7개를 저장소 루트에 업로드합니다.
3. Commit changes 후 https://jiyeolbae.github.io 에서 업데이트 결과를 확인합니다.
4. 페이지가 이전 모습이면 몇 분 기다린 후 강력 새로고침(Ctrl+F5)합니다.

참고: 미래 웹툰은 '앞으로 이루고 싶은 꿈'을 시각화한 창작물이며, 이미 창업/기부 사업을 완료했다는 의미가 아닙니다.
